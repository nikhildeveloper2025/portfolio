# Frontend Developer Portfolio

A modern, dark-themed personal portfolio built with **Next.js**, **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## Features

- Dark-first UI with gradient glow accents
- Sticky navbar + smooth scrolling
- Responsive layout (mobile/tablet/desktop)
- Animated sections and cards with Framer Motion
- SEO metadata configured in App Router layout
- Accessible semantic sections and form labels
- Ready for Vercel deployment

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push repository to GitHub
2. Import project on Vercel
3. Deploy (defaults are preconfigured for Next.js)
